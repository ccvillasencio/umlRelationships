# UML Relationships

This repository contains Python code examples
for six UML relationships.

## Relationships

1. Inheritance (Is-a)
2. Composition (Strong Has-a)
3. Aggregation (Weak Has-a)
4. Association (Knows-a)
5. Dependency (Uses-a)
6. Realization / Implementation (Implements)

## Language

Python
