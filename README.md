# UML Relationships

This repository contains Python code examples
for six UML relationships.

## Relationships

1. Inheritance (Is-a)
2. Composition (Strong Has-a)
3. Aggregation (Weak Has-a)
4. Association (Knows-a)
5. Dependency (Uses-a)
6. Realization / Implementation (Implements)

## Language

Python

## EXER 2 REFLECTION
# Reflection: Why is it better to access __age through get_age()?
  Using get_age() protects the data from accidental changes outside the class.
  It also lets us control how the age is viewed or add validation rules later.
